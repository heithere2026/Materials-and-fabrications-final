# 大三巴教堂收納盒 · 3D 組裝圖

雷射切割功課的 3D 組裝預覽。純 HTML + Canvas，不需要任何套件或建置步驟。

## 部署到 GitHub Pages
1. 在 GitHub 建立新 repository（例如 `ruins-box-3d`），設為 Public。
2. 上傳 `index.html`（和這個 README）到 repository 根目錄。
3. 到 **Settings → Pages**，Source 選 **Deploy from a branch**，Branch 選 `main`、資料夾 `/ (root)`，按 Save。
4. 等一兩分鐘，網址會是 `https://<你的帳號>.github.io/ruins-box-3d/`。

## 操作
拖曳旋轉、滾輪縮放；拉桿拆開零件；按鈕掀起屋頂、拉出抽屜、看背面；點零件名稱高亮，Esc 或「取消選取」還原。
